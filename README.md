# 🎮 GameVault Deals

**Unlock Legendary Savings on PC Games**

A modern, sleek web application that helps gamers discover the best discounts on PC games from legitimate platforms only. No sketchy key resellers, no gray markets - just genuine deals from trusted gaming stores.

---

## 🌟 Features

### 🔍 Smart Filtering & Sorting
- **Search**: Find specific games by title
- **Store Filter**: Filter by your favorite platforms (Steam, Epic Games, GOG, EA Origin, etc.)
- **Discount Filter**: Show only deals with minimum discount percentages (10%, 25%, 50%, 75%)
- **Price Filter**: Set a maximum price range
- **Sort Options**:
  - Best Deals (by deal rating)
  - Highest Discount
  - Lowest Price
  - Most Recent
  - Alphabetical

### 🎯 Legitimate Platforms Only
We only show deals from verified, legal gaming platforms:
- **Steam**
- **Epic Games Store**
- **GOG** (Good Old Games)
- **Origin** (EA)
- **Humble Store**
- **GreenManGaming**
- **GamersGate**
- **Fanatical**
- And many more trusted retailers

### 💎 Beautiful Design
- Modern, gaming-themed UI with smooth animations
- Responsive design works on desktop, tablet, and mobile
- Dark theme optimized for comfortable viewing
- Gradient accents and hover effects
- Clean, intuitive interface

### ⚡ Performance
- Fast loading with API caching
- Smooth filtering and sorting
- Debounced search for optimal performance
- Lazy loading images

## 📊 API Integration

This application uses the [CheapShark API](https://apidocs.cheapshark.com/), which aggregates deals from legitimate gaming platforms.

### Key Features of the API
- Real-time deal tracking
- Multiple legitimate stores
- Deal ratings and metadata
- No API key required for basic usage

### Data Refresh
- Deals are cached for 5 minutes to improve performance
- Automatic refresh when cache expires
- Manual refresh available by reloading the page

## 🎮 About the Project

**GameVault Deals** was created to help gamers find legitimate deals without supporting gray market key resellers. We believe in supporting game developers and publishers while still finding great prices from authorized retailers.

### Why This Matters
- **Support Developers**: Buying from legitimate sources ensures developers get paid
- **No Risk**: Avoid key revocations and account bans from unauthorized sellers
- **Better Gaming Ecosystem**: Help maintain a healthy gaming market
- **Peace of Mind**: All deals are from verified, trusted platforms
